# 🧪 SciMathWizard — Student Testing Guide

**App URL:** https://scimathwizard.lovable.app  
**Testing Period:** March 2026  
**Time Required:** ~20-30 minutes per tester

---

## 👋 Hello Testers!

Thank you for helping us test SciMathWizard! Your feedback will make this app better for all students. Please follow the tests below and record your results in the **Score Sheet** at the bottom.

> **Important:** Use your phone OR laptop — note which device you're using!

---

## 🔧 Before You Start

1. Open the app: **https://scimathwizard.lovable.app**
2. Note your **device** (Phone model / Laptop) and **browser** (Chrome / Safari / etc.)
3. You do NOT need to sign up for basic testing — some tests require sign-up

---

## Test 1: First Visit Experience ⭐
**Time: 3 minutes | No login needed**

| Step | What to do | What should happen | ✅/❌ |
|------|-----------|-------------------|-------|
| 1.1 | Open the app link | App loads without errors, you see a welcome screen or dashboard | |
| 1.2 | If a welcome popup appears, read it | It should explain what the app does | |
| 1.3 | Close/dismiss the welcome popup | Dashboard with Math topics should appear | |
| 1.4 | Look at the top of the screen | You should see subject tabs (Math, Physics, Chemistry) | |
| 1.5 | Look for a mode badge (📚 Focused or 🎮 Fun) | Badge should be visible near the top | |

**Write down:** What was your first impression? Was anything confusing?

---

## Test 2: Quiz Flow ⭐⭐ (Most Important!)
**Time: 5-7 minutes | No login needed**

| Step | What to do | What should happen | ✅/❌ |
|------|-----------|-------------------|-------|
| 2.1 | Find "Integers" in the topic list and tap/click it | Topic expands showing level buttons (Level 1, 2, etc.) | |
| 2.2 | Tap "Level 1" | A quiz question appears with 4 answer choices (A, B, C, D) | |
| 2.3 | Read the question carefully | Question text is clear and readable | |
| 2.4 | Select an answer | Your choice is highlighted | |
| 2.5 | Check the feedback | You should see if you were correct or wrong, with an explanation | |
| 2.6 | Answer 5 more questions (6 total) | Progress updates (e.g., "3/10 correct") | |
| 2.7 | Look for a "Hint" button | Tapping it shows a helpful hint (FREE, no cost) | |
| 2.8 | Continue until you finish 10 questions OR tap "End Session" | Session summary appears showing your score | |

**Write down:**
- Were the questions appropriate for your grade level?
- Was any question confusing or incorrectly worded?
- Did the hints help?
- Did anything freeze or break?

## Test 3: Switching Subjects
**Time: 2 minutes | No login needed**

| Step | What to do | What should happen | ✅/❌ |
|------|-----------|-------------------|-------|
| 3.1 | Go back to the dashboard (home screen) | Dashboard loads | |
| 3.2 | Tap "Physics" tab | Physics topics appear (different from Math) | |
| 3.3 | Tap "Chemistry" tab | Chemistry topics appear | |
| 3.4 | Tap "Math" tab again | Math topics come back | |
| 3.5 | Close the app completely, then reopen | The last subject you selected should still be active | |

## Test 4: Learning Mode Toggle
**Time: 3 minutes | No login needed**

| Step | What to do | What should happen | ✅/❌ |
|------|-----------|-------------------|-------|
| 4.1 | Find and tap the Profile icon (bottom nav or top) | Profile page opens | |
| 4.2 | Look for "Learning Mode" toggle | You should see Focused / Fun mode options | |
| 4.3 | Switch to **Fun Mode** (🎮) | Page styling may change, badge updates to 🎮 Fun | |
| 4.4 | Go back to dashboard | You should see Star Shop, more colorful elements | |
| 4.5 | Go to Profile → switch to **Focused Mode** (📚) | Dashboard becomes cleaner, Star Shop hidden | |
| 4.6 | Start a quiz in Focused Mode | Stats show "Accuracy %" instead of stars | |

**Write down:** Which mode do you prefer and why?

## Test 5: Sign Up & Report ⭐⭐
**Time: 5 minutes | Requires sign-up**

| Step | What to do | What should happen | ✅/❌ |
|------|-----------|-------------------|-------|
| 5.1 | Tap "Sign In" or the login button | Auth page appears | |
| 5.2 | Choose "Sign Up" and enter your email + password | Account creation starts | |
| 5.3 | Check your email for a verification link | You should receive a verification email | |
| 5.4 | Click the verification link, then sign in | You're now logged in, dashboard shows your name/avatar | |
| 5.5 | Complete a full quiz session (10 questions) | Session summary appears with your results | |
| 5.6 | Look for a success toast/notification | "Session saved!" message should appear | |
| 5.7 | Tap "Report" in the navigation | Report page loads | |
| 5.8 | Check if your session appears in the report | Your recent session should be listed with correct stats | |

**Write down:** Did your session data appear correctly in the report?

## Test 6: Mobile Experience
**Time: 3 minutes | Phone only**

| Step | What to do | What should happen | ✅/❌ |
|------|-----------|-------------------|-------|

## Test 7: Edge Cases & Breaking Things 💥
**Time: 3 minutes | Try to break it!**

| Step | What to do | What should happen | ✅/❌ |
|------|-----------|-------------------|-------|
| 7.1 | Tap an answer really fast multiple times | Only one answer should register | |
| 7.2 | Turn off internet, then try to use the app | You should see an offline indicator, not a crash | |
| 7.3 | Turn internet back on | App should recover automatically | |
| 7.4 | Press the browser back button during a quiz | App should handle it gracefully (no crash) | |
| 7.5 | Open app in two tabs at the same time | Both should work without conflict | |

## 🎁 Thank You!

Your testing helps make this app better for thousands of students. Please send your completed score sheet back so we can fix any issues you found!

**Tips for good bug reports:**
- Screenshot the error if you see one
- Note exactly what you tapped/clicked before the issue happened
- Mention your device and browser
- "It broke" → ❌ Not helpful
- "I tapped Level 2 on Integers, the screen went white on Chrome/iPhone" → ✅ Very helpful!
